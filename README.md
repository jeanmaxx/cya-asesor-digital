# C&A · Asesor Digital

Landing móvil reutilizable para asesores previsionales de Casillas & Asociados.

## Personalización rápida

Los datos del asesor viven en `assets/config.js`:

- nombre
- cargo
- teléfono / WhatsApp
- mensaje inicial de WhatsApp
- Instagram
- Facebook
- fotografía
- logotipo

La página oculta automáticamente Instagram/Facebook mientras sus URLs estén vacías.

## Publicación

Pensado para GitHub Pages como sitio estático (HTML/CSS/JS, sin dependencias externas).
